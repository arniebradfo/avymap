# Avymaps

## Map
Data points need:
- Elevation - [Mapbox](https://blog.mapbox.com/global-elevation-data-6689f1d0ba65)
- Slope - [ArcGIS](http://desktop.arcgis.com/en/arcmap/10.3/tools/spatial-analyst-toolbox/how-slope-works.htm)

- Fall line?
